# حكمة (Hikma): ملف اللجنة

**الفكرة:** قلم ذكي بيقرأ الكتب الورقية بصوت عالٍ، والموقع ده نموذج تجريبي (demo) لتجربة القلم.

**الفئات:** أطفال 4-8، ذوو الإعاقة والمكفوفون، وطلاب 16-30 بيذاكروا من كتب مرجعية.

**الميزة الرئيسية: إتاحة الوصول**
- وضع الديسلكسيا، مسطرة التركيز، التحكم بزر واحد/لوحة المفاتيح
- تباين عالٍ فاتح وداكن، إعلان الجملة لقارئ الشاشة
- التحكم بالصوت والسرعة ومؤقت النوم
- ملاحظات وعلامات للطلاب، بطاقات مراجعة، اختبار بعد كل نص

**تشغيل نسخة بدون إنترنت:** `npm ci && npm run dev` ثم افتح http://localhost:4173 (التطبيق PWA ويشتغل بعد أول تحميل بدون نت).

**الاختبارات:** `npm test` و `npm run lint`.

**ملفات:** `design-diagram.md` (رسم التصميم)، `video-script.md` (سيناريو فيديو دقيقتين)، `pricing.md` (جدول الأسعار).
