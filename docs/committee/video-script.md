# سيناريو فيديو دقيقتين

1. (0:00-0:15) طفل ومكفوف وطالب جامعي: كل واحد عنده مشكلة قراءة مختلفة.
2. (0:15-0:35) نمرر القلم على سطر في كتاب، الجملة بتتقرأ وتتلوّن.
3. (0:35-1:05) عرض الإتاحة: ديسلكسيا، مسطرة التركيز، التباين العالي، التحكم بزر واحد.
4. (1:05-1:30) الطالب: ضغطة على كلمة للمعنى، حفظها كبطاقة، ملاحظة، اختبار.
5. (1:30-1:50) مكتبة التراث، مشاركة قصة برابط أو QR.
6. (1:50-2:00) الخاتمة: القراءة حق للجميع.
