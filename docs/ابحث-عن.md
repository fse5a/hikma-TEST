## قواعد سريعة
- الأسماء البرمجية بالإنجليزي، والشرح بالعربي فوقها.
- أي تعديل في ملفات الواجهة لا تحتاج تغيير رقم النسخة: البناء بيعمله تلقائيًا.
- للتشغيل والاختبار: `npm test` ثم `npm run build`.
