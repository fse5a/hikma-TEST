# بروتوكول القلم (مسودة للمحاكي)

القلم الحقيقي لسه مش موجود. الملف ده بيحدد الشكل اللي المحاكي بيستخدمه، والقلم الحقيقي يتعمل بحيث يطابقه (أو نعدّله مع بعض).

## حدث المسح `pen.scan`

JSON واحد لكل جملة القلم مسحها:

```json
{
  "version": 1,
  "type": "pen.scan",
  "deviceId": "SIM-PEN-001",
  "seq": 1,
  "ts": "2026-11-25T17:00:00.000Z",
  "lang": "ar",
  "text": "كان يا ما كان...",
  "confidence": 0.97,
  "battery": 98,
  "source": "simulator"
}
```

| الحقل | المعنى |
| --- | --- |
| `version` | رقم نسخة البروتوكول (دلوقتي 1) |
| `type` | نوع الحدث (`pen.scan` بس) |
| `deviceId` | اسم القلم (3 إلى 40 حرف/رقم/شرطة) |
| `seq` | رقم متسلسل يبدأ من 1، عشان نعرف لو حدث ضاع أو اتكرر |
| `ts` | وقت المسح (ISO) |
| `lang` | اللغة: ar, en, fr, de, es, zh |
| `text` | الجملة اللي اتمسحت (1 إلى 2000 حرف) |
| `confidence` | ثقة القراءة من 0 إلى 1 |
| `battery` | نسبة البطارية (اختياري) |
| `source` | `simulator` للمحاكي، والقلم الحقيقي يكتب `pen` |

## تشغيل المحاكي

**سطر الأوامر:**

```bash
node iot/simulator/pen-sim.mjs                       # 3 أحداث على الشاشة
node iot/simulator/pen-sim.mjs --count 5 --lang en   # 5 جمل إنجليزي
node iot/simulator/pen-sim.mjs --text "جملتي" --post http://localhost:4000/pen
```

**صفحة اختبار:** افتح `iot/simulator/index.html` في المتصفح (نقر مزدوج). اكتب جملة واضغط «مسح الجملة»، وهتشوف الحدث. ممكن تحط رابط عشان تتبعت له.

**الاختبار:** `npm test` فيه اختبار للمحاكي (`iot/tests/`).

## لسه ناقص
- مفيش endpoint في الباك إند بيستقبل أحداث القلم. لما القلم يتعمل: ضيف handler في `backend/handlers/` وتحقق من `deviceId` وحدّ الاستخدام.
- ازاي القلم هيتوصل (بلوتوث أو واي فاي) لسه قرار مفتوح.
- أمان الجهاز (تعريف القلم وتشفير الاتصال) لسه ماتصمّمش.
